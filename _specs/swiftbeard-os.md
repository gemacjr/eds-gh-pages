## Problem

A list of links doesn't show what my iOS apps, Spring Boot APIs, and websites can do. Presenting
them in a working "operating system" makes the portfolio itself a demo.

## Goals

- Windowed desktop with a dock and side buttons that work like a real OS
- Four completely different wallpaper themes, including a Tron-like city
- Original playable games (BeardBox, a layer game, a flying game)
- **API demos:** animate a request as it flows through REST → gateway → Fargate/EC2 → database → Kafka, showing response times

## Iterations

- Fixed overlapping dock buttons and side buttons that didn't respond
- Made the API demo windows larger so response times weren't cut off
- Polished the games and wallpapers to look professional
