## Problem

React was the weakest part of my full-stack story. This is a small app that covers the
fundamentals with an API that needs no setup.

## Goals

- Create, read, update, and delete posts against [JSONPlaceholder](https://jsonplaceholder.typicode.com/)
- React 19 + TypeScript, built with Vite
- `LEARNING.md` explains each concept next to where it appears in the code
