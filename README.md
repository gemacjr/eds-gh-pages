# Project Specs

Specifications for projects I build with Claude Code and Cursor, published at
https://gemacjr.github.io/eds-gh-pages/

- New spec: copy `_templates/spec.md` to `_specs/<name>.md`
- Local preview: `npm install && npm run watch:css`, then `bundle exec jekyll serve`
- Deploys: GitHub Actions builds Tailwind + Jekyll on every push to `main`

See `CLAUDE.md` for the front matter conventions.
